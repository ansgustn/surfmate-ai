# 🏄 SurfMate AI — 초보 서퍼를 위한 맞춤형 해양 에이전트 및 혼잡도 예측 시스템

> 2025년도 「스마트 해운물류 × ICT멘토링」 프로젝트
> **주제영역:** 인공지능(AI) 및 데이터 분석 · **프로젝트 목표:** 기술교육

파도를 읽는 데 익숙하지 않은 초보 서퍼와 해양 레저 입문자를 위해 **해상 공공데이터 + 공간 데이터베이스 + LLM**을 결합한 맞춤형 지능형 에이전트를 만듭니다.
사용자의 실력과 위치를 기반으로 가장 안전하고 적합한 서핑 스팟을 추천하고, 다변량 데이터 분석으로 라인업(파도 대기 구역)의 혼잡도를 미리 예측하는 **상황 인지형(Context-Aware) 서핑 가이드**를 목표로 합니다.

## 📌 제안 배경

| 문제 | 설명 |
|---|---|
| 원시 데이터 위주의 서비스 | Windy, 기상청 등은 파고·풍향 같은 원시 수치만 보여줘서, 초보자가 자기 수준에 맞는 파도·지형인지 스스로 판단하기 어렵습니다. |
| 라인업 혼잡으로 인한 사고 위험 | 서핑 인구가 늘면서 유명 해변에 사람이 몰려 충돌·파도 선점 문제가 생기지만, 이를 미리 예측하는 시스템이 없습니다. |
| 초보자 특화 판단 기준 부재 | 초보자에게는 **파고 0.5~1m 내외**, **모래(Sand) 해저**처럼 안전한 환경이 필요합니다. 지형 정보와 실시간 기상을 교차 분석하는 엔진이 필요합니다. |

## ✨ 주요 기능

1. **동적 기상 연동 추천 스팟 산출**
   실시간 해양 기상 API(파고, 파주기, 풍향, 조위)를 연동해 초보자 기준에 따라 스팟 상태를 실시간으로 분류합니다.
   - 🟢 입수 최적 · 🟡 주의 요망 · 🔴 입수 자제
2. **해저 지형 및 환경 특성 자동 매칭**
   해변 이름이나 위치를 입력하면 PostGIS 공간 데이터로 해저 지형(Sand, Reef 등)과 수심 특성을 조회하고, 롱보드/숏보드 적합성과 안전 가이드를 제시합니다.
3. **다변량 기반 라인업 혼잡도 예측**
   기상, 계절, 요일, 시간대, 인근 서핑 스쿨 일정 등을 융합 분석(CNMV)해서 해변별·시간대별 혼잡도를 예측하고 신호등 지표로 보여줍니다.
4. **상황 인지형 대화형 대시보드**
   서핑 지역 전체의 기상과 혼잡도를 통합 지도로 보여줍니다. 혼잡하거나 위험하면 LLM 에이전트가 근처의 여유 있는 대체 스팟을 먼저 추천합니다.

## 📦 예상 결과물 — **SurfMate AI**

사용자용 모바일 웹/앱 서비스로, 맞춤형 서핑 스팟 추천과 혼잡도 예측 지표를 시각화합니다.

### ① 맞춤형 서핑 스팟 추천 (모바일 홈)
- 현재 조건 요약 카드: **파고**(예: 0.8 m, 적정) · **풍향**(예: 북서풍, 약함) · **조위**(예: 0.6 m, 상승)
- **추천 스팟 TOP 3** 리스트: 해변명, 파고 범위, 해저 지형, 한 줄 코멘트, 상태 배지
  - 예) 송정 해변 `입수 최적` · 다대포 해변 `입수 가능` · 일광 해변 `주의 요망`

### ② 통합 지도 대시보드 (태블릿/웹)
- 좌측 메뉴: 지도 · 추천 스팟 · 혼잡도 예측 · 설정
- 지도 위 스팟 마커 + 상태 라벨 (입수 최적 / 혼잡 주의 / 입수 가능 / 주의 요망)
- 선택한 해변 상세 패널: 기온·날씨, 파고, 파주기, 풍향·풍속, 조위
- **혼잡도 예측**: 현재 시각 혼잡도 + 시간대별 혼잡도 (오전 9–12시, 오후 12–3시, 3–6시, 6–9시)
- 범례: 입수 최적 · 입수 가능 · 주의 요망 · 입수 자제

### ③ AI 에이전트 챗봇
- 자연어 질문 → 현재 컨디션 분석 + 대안 스팟 제시
  - 예) "지금 해운대 해변 어때?" → "파고 1.2 m로 초보자에게 다소 높고 라인업 혼잡도도 높습니다. 송정 또는 다대포를 추천드려요."
- 응답 하단에 **대안 스팟 추천** 카드 (해변명, 파고, 혼잡도)

### 데이터 파이프라인 아키텍처

| 단계 | 구성 |
|---|---|
| **Data Sources** | 기상청(해양 기상 API) · 국립해양조사원(해양 지형/수심 데이터) · 공간 데이터(해저 지형, 해변 정보) · 기타 데이터(계절, 요일, 시간대, 서핑 스쿨 일정) |

## 🚀 시작하기

### 백엔드 (FastAPI)

DB 없이도 `db/seed/spots.json` 으로 바로 실행됩니다. 기상값은 다음 순서로 채웁니다.

1. **기상청 해양기상종합관측 실측** (`backend/.env` 에 `KMA_AUTH_KEY` 가 있을 때): 스팟에서 15km 안의 가장 가까운 파고 관측 지점(해수욕장 파고부이 등)과 바람 관측 지점. 10분 캐시.
2. **[Open-Meteo](https://open-meteo.com/) 예보** (인증키 불필요): 기상청 값이 없는 항목(파주기·조위)과 15km 안에 관측 지점이 없는 스팟. 15분 캐시.
3. **가짜(mock) 데이터**: 위가 모두 실패할 때. 오프라인 개발 시 `WEATHER_PROVIDER=mock` 으로 실행하세요.

기상청 API허브(apihub.kma.go.kr)에서 **해양관측 → 1.1 해양기상종합관측** 활용신청 후 받은 인증키를 `backend/.env` 에 넣습니다 (`.env.example` 참고).

### 공공데이터포털 (혼잡도)

공공데이터포털(data.go.kr)에서 아래 두 API 를 활용신청하고, 일반 인증키(Decoding)를 `backend/.env` 의 `DATA_GO_KR_KEY` 에 넣습니다.

- 한국관광공사_관광지 집중률 방문자 추이 예측 정보 — 혼잡도 추정에 사용
- 한국관광공사_빅데이터_지역별 방문자수 — 학습용 이력 수집 (`scripts/collect_visitors.py`)
- 한국관광공사_국문 관광정보 서비스_GW — 서핑 해안 해변 목록·좌표 (`scripts/import_beaches.py` → `db/seed/spots_auto.json`)
  - 자동 수집 해변은 지형을 모르므로 `bottom_type: unknown` → 안전 등급 최소 '주의 요망'. 현장 확인 후 `spots.json` 으로 옮겨 정리

> ⚠️ 동서대 교내 네트워크에서는 data.go.kr 접속이 차단되어 있습니다 (연결 시간 초과). 휴대폰 핫스팟 등 다른 네트워크를 쓰세요. 접속이 안 되면 혼잡도는 요일·계절 규칙으로 자동 대체되고, 10분 동안 재시도하지 않습니다.

```bash
cd backend
python -m venv .venv
.venv/Scripts/activate        # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8010
```

- API 문서: http://localhost:8010/docs
- 테스트: `pytest`

| 엔드포인트 | 설명 |
|---|---|
| `GET /spots` | 스팟 목록 |
| `GET /spots/{id}` | 스팟의 현재 기상 + 안전 등급(입수 최적/주의 요망/입수 자제)과 이유 |
| `GET /recommend?lat=&lon=&max_km=50&limit=3` | 초보자 추천 스팟 (안전 등급 → 거리 → 적정 파고 순) |
| `POST /chat` | AI 에이전트 챗봇. `{message, history, lat, lon}` → `{reply, spot, alternatives}` |

### AI 챗봇 (Ollama 로컬 LLM)

[Ollama](https://ollama.com/) 를 설치하고 모델을 받아 둡니다. 기본 모델은 `qwen2.5:7b`(약 4.7GB, 3b 보다 정확해서 기본값으로 선택) 이며 `backend/.env` 의 `OLLAMA_MODEL` 로 바꿀 수 있습니다.

```bash
ollama pull qwen2.5:7b
```

LLM 이 수치를 지어내지 않도록, 현재 모든 스팟의 기상·안전 등급을 시스템 프롬프트에 넣고 질문한 해변과 대안 스팟은 코드가 정해서 함께 넘깁니다 (`backend/app/chat.py`).

### 프론트엔드 (React + Vite)

백엔드를 먼저 켠 뒤 실행합니다. `/api/*` 요청은 Vite가 `localhost:8010`으로 넘겨줍니다 (다른 주소면 `API_URL` 환경변수로 지정).

```bash
cd frontend
npm install
npm run dev
```

- http://localhost:5173
- 화면: 홈(추천 스팟 TOP 3) · 지도(스팟별 안전 등급, 상세 패널) · 챗봇(대화형 안내, 대안 스팟 카드)
